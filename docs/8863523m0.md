# Claude Code Window系统安装教程

## 1、安装 Git Bash

Claude Code在Windows上内部是用Git Bash来执行命令的，所以要想在Windows上用Claude Code，必须先把Git安装上。

所以第一步，我们先把Git装上。

已经装好的朋友可以跳过这一趴。

用WinGet来装，这个东西是Windows官方的包管理器，可以理解成Windows版本的Homebrew。

我们在任务栏搜索终端打开。

![0ec9ec58d656224b416385fbc3c591f0.jpg](https://api.apifox.com/api/v1/projects/8166793/resources/650387/image-preview)

粘贴下面的命令到终端，这里安装的时候不开魔法速度会快很多。

```
winget install Git.Git
```

跑完就会显示成功安装了。

![471038dbf8f4555ff5f560b5971c6d0c.jpg](https://api.apifox.com/api/v1/projects/8166793/resources/650388/image-preview)

Git装好了之后。
## 2、安装Claude Code
### 2.1、如果有魔法的情况。

有魔法的朋友，我们还是用他官方的原生安装命令。

粘贴命令到终端。

```
irm https://claude.ai/install.ps1 | iex
```

![7a55b642765f0735af5ffa8bc2223ae5.png](https://api.apifox.com/api/v1/projects/8166793/resources/650389/image-preview)

等一会就安装好了。

![2de17be4ef137bdb2fce899af29aae95.jpg](https://api.apifox.com/api/v1/projects/8166793/resources/650390/image-preview)


非常便捷。

### 2.2、没有魔法的情况
如果没魔法的话，我们就得使用WinGet来安装。

在终端中运行这行命令。


```
winget install Anthropic.ClaudeCode
```

![58c5e80528da20df67b57d4429e460e0.png](https://api.apifox.com/api/v1/projects/8166793/resources/650391/image-preview)

等他安装成功后，同样可以输入claude，就能看到已经安装成功了。

![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/650392/image-preview)

到这一步，从道理上讲，我们在终端里输入claude，就能进到Claude Code页面了。
