# 对话模型网页使用教程

# 1、创建API令牌
查看[API令牌创建教程](https://token173.apifox.cn/doc-8680758) 创建API令牌。

# 2、进入chatgpt-web-mj 
1. 进入 [API控制台](https://token173.com/console)。
2. 选中聊天工具中的 chatgpt-web-mj 进入。
3. 选择API令牌，建议按[API令牌创建教程](https://token173.apifox.cn/doc-8680758)创建auto API令牌。
4. 点击确认进入。

![image.png](https://api.apifox.com/api/v1/projects/8343734/resources/660384/image-preview)
# 3、创建对话
1. 进入对话。
2. 新建对话。
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/658861/image-preview)

# 4、指定模型
1. 点击模型。
2. 点击服务器获取。
:::caution[]
下拉框中的模型不全，使用服务器获取所有可用模型。
:::
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/658862/image-preview)
3. 搜索选择模型保持。推荐 gpt-5.5、claude-opus-4-7 最强。 
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/658863/image-preview)
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/658864/image-preview)
