# 视频模型网页使用教程

# 1、创建API令牌
查看[API令牌创建教程](https://token173.apifox.cn/doc-8680758) 创建API令牌。

# 2、进入chatgpt-web-mj
1. 进入 [Token173 API控制台](https://token173.com/console)。
2. 选中聊天工具中的 chatgpt-web-mj 进入。
3. 选择API令牌，建议按[API令牌创建教程](https://token173.apifox.cn/doc-8680758)创建auto API令牌。
4. 点击确认进入。

![image.png](https://api.apifox.com/api/v1/projects/8343734/resources/661805/image-preview)
# 3、进入视频
1. 进入视频。
2. 选择视频模型。推荐 HappyHorse、Kling、Vidu 等。
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/658867/image-preview)

# 4、模型使用
按需指定生成模式、具体模型、提示词等信息使用。
