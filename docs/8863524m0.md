# Claude Code 通过 CC Switch 接入诗云API教程

CC Switch是一款非常方便的为各种软件设置或切换使用模型的软件。
当前主要支持Claude、Codex、Gemini、OpenCode、OpenClaw 等软件。

[CC Switch Mac系统安装教程](https://shiyunapi.apifox.cn/doc-8676350)
[CC Switch Windows系统安装教程](https://shiyunapi.apifox.cn/doc-8676351)


以下是使用CC Switch设置Claude Code使用接入诗云API的教程。

选中Claude，点击右上角的+号增加供应商。
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/650381/image-preview)

选择自定义配置
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/650382/image-preview)

下拉设置供应商信息

设置 供应商名称
官网链接设置为 https://shiyunapi.com
API KEY设置为在诗云API[API密令管理](https://shiyunapi.com/console/token)中创建的API KEY.
请求地址设置为 https://shiyunapi.com
API格式认证字段都使用默认设置
各模型设置成在诗云API中想使用的模型名称，建议通过复制来设置，防止错误。

![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/650383/image-preview)

![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/650385/image-preview)

设置完信息后点击右下角添加完成供应商设置。

最后回到Claude下选中刚设置的诗云API供应商点击启用。
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/650384/image-preview)

:::danger[]
最后最后重启Claude Code 配置才能生效。
:::

如果想多个模型切换来测试使用可以设置多个不同的供应商，然后同步启动不同的供应商来切换模型。
