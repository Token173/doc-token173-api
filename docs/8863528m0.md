# Codex Window系统安装教程

### 系统要求
- Windows 10 或 Windows 11
- Node.js 22+
- npm 10+
- 网络连接

### 桌面版安装方法（推荐）
方式一：无需魔法，直接点击 [下载链接](https://img.skyai.tech/shiyunapi/Codex%20Installer.exe) 下载，运行按提示安装。

方式二：需要魔法，访问 [Codex](https://openai.com/zh-Hans-CN/codex/) 官网下载Codex 桌面版，运行按提示安装。

### 命令行安装方法

**前置步骤！！！**
安装 Git Bash，请访问 [Git - Downloads](https://git-scm.com/downloads) 下载对应您电脑系统的版本，之后一直点击“下一步”即可完成安装。

**1. 安装 Node.js**
访问 [Node.js 官网](https://nodejs.org/) 下载并安装最新 LTS 版本。

**2. 安装 codex**
打开命令提示符 (CMD) 或 PowerShell，运行：
```bash
npm install -g @openai/codex
````

**3. 验证安装**
打开命令提示符 (CMD) 或 PowerShell，运行：

```bash
codex --version
```
