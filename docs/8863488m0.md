# Claude Code 使用Token173 API教程

## 一、安装Claude Code
如果没有安装Claude Code，根据系统不同查看对应教程安装好Claude Code.
 [Claude Code Mac系统安装教程](https://token173.apifox.cn/doc-8676226)
 [Claude Code Window系统安装教程](https://token173.apifox.cn/doc-8676227)
 
## 二、安装CC Switch 
如果没有安装CC Switch，根据系统不同查看对应教程安装好CC Switch。CC Switch用来接入和切换模型。
 [CC Switch Mac系统安装教程](https://token173.apifox.cn/doc-8676350)
 [CC Switch Windows系统安装教程](https://token173.apifox.cn/doc-8676351)
 
## 三、CC Switch接入Token173 API
[Claude Code 通过 CC Switch 接入API教程](https://token173.apifox.cn/doc-8676352)
