# Nano Banana 网页使用教程

# 1、创建API令牌
查看[API令牌创建教程](https://token173.apifox.cn/doc-8680758) 创建API令牌。

# 2、进入chatgpt-web-mj
1. 进入 [API控制台](https://token173.com/console)。
2. 选中聊天工具中的 chatgpt-web-mj 进入。
3. 选择API令牌，选择的API令牌一定支持gpt-image-2模型，建议按[API令牌创建教程](https://token173.apifox.cn/doc-8680758)创建auto API令牌。
4. 点击确认进入。

![image.png](https://api.apifox.com/api/v1/projects/8343734/resources/661803/image-preview)

# 3、进入gpt-image-2模型
1. 点击绘图。
2. 选择Nano Banana。
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/658855/image-preview)

3. 版本选择
 gemini 2.5 Flash Image -> Nano Banana
 gemini-3-pro-image-preview -> Nano Banana pro
 gemini-3.1-flash-image-preview -> Nano Banana 2
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/658856/image-preview)

# 4、模型使用
1. 文生图 根据文字生成图片，其他参数根据需要自由设置。
2. 图片编辑模式支持选择参考图进行图片生成，其他参数根据需要自由设置。
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/658859/image-preview)
