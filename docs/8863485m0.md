# 二、通用工具接入教程
1. 找到工具的自定义模型设置入口。
2. 尝试按下表填写相关或类似字段。

| 参数名 | 参数值 | 说明 |
| --- | --- | --- |
| API 协议 | OpenAI Completions、OpenAI | 接口的协议类型，建议选OpenAI Completions、OpenAI, 这个是OpenAI的接口协议，所有对话模型都兼容。 |
| API Base URL | https://token173.com  https://token173.com/v1  | 接口的请求基础地址，每个工具配置方式不一样有些工具需要带/v1，有些不需要，可以尝试下。或者如果有示例按示例填写。 |
| API Key | 示例：sk-xxxxxxxxxxxxxxxxxxxxxxxxx| 接口授权令牌，建议按 [API令牌创建教程](https://token173.apifox.cn/doc-8680758) 创建API令牌，再复制API令牌填写。 |
| Model Name | 示例：gpt-5.5、claude-opus-4-7、gemini-3.5-flash | 模型名称，建议在 [模型广场](https://token173.com/pricing) 选择支持的模型，再复制模型名填写。|

3. 接入失败尝试 [联系我们](https://Token173.com/customersupport) 寻求帮助。
