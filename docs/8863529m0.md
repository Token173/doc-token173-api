# Codex Mac系统安装教程

### 系统要求

  - macOS 12 或更高版本
  - Node.js 22+
  - npm 10+
  - 网络连接

### 桌面版安装方法（推荐）
方式一：无需魔法，直接点击 [下载链接](https://img.skyai.tech/shiyunapi/Codex.dmg) 下载，运行按提示安装。
方式二：需要魔法，访问 [Codex](https://chatgpt.com/zh-Hans-CN/download/) 官网下载Codex 桌面版，运行按提示安装。

### 命令行安装方法

**1. 安装 Node.js**

  - **方式一**：直接访问 [Node.js 官网](https://nodejs.org/) 下载并安装最新 LTS 版本。
  - **方式二**：使用 Homebrew（推荐）
    ```bash
    # 如果尚未安装 Homebrew，请先运行此命令
    /bin/bash -c "$(curl -fsSL [https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh](https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh))"

    # 安装 Node.js
    brew install node
    ```

**2. 安装 codex**
打开终端 (Terminal)，运行（可能需要加 `sudo`）：

```bash
npm install -g @openai/codex
```

**3. 验证安装**
打开终端 (Terminal)，运行：

```bash
codex --version
```
