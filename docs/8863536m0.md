# Cherry Studio 增加Claude模型使用教程

# 一、增加服务商
进入 设置->模型服务->添加 来添加服务商
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/657327/image-preview)

供应商名称 可以随便填，为了好记可以加上OpenAI字样。
供应商类型 选上Anthropic
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/657332/image-preview)
# 二、设置密钥地址
API密钥 按照 [API令牌创建教程](https://token173.apifox.cn/8863486m0.md) 教程创建好之后填上。
API地址 填 https://shiyunapi.com
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/657335/image-preview)

# 三、选择模型
模型 点获取模型列表 搜索想要添加的模型添加上。
推荐选上 **claude-opus-4-7、
claude-sonnet-4-6、claude-haiku-4-5-20251001**
 作为对话模型。
这3个模型是Claude的最新模型，价格和能力 opus>sonnet>haiku 。
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/657336/image-preview)
