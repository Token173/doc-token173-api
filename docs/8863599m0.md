# Token173 API开票教程

支持给企业开增值税普通发票。

<Steps>
  <Step title="实名认证">
进入 控制台->个人设置 中进行企业实名认证。
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/653639/image-preview)
  </Step>
  <Step title="开发票">
进入 控制台->钱包 中选择订单进行开票
      ![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/653636/image-preview)
  </Step>
  <Step title="下载发票">
正常1、3个工作日开好发票。
发票会发送到接收邮箱也可以
进入 控制台->钱包 开票记录中下载发票。
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/653641/image-preview)
  </Step>
</Steps>
