# Trea 使用Token173 API教程

### 1、添加模型
进入设置->模型->添加模型
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/651782/image-preview)

### 2、使用OpenAI兼容接口模型
服务商：OpenAI
模型：自定义模型
模型ID: 选择 [模型广场](https://token173.com/pricing) 中支持 openai:/v1/chat/completions 的模型，复制模型名填写到模型ID中。
Claude、deepseek等都支持，基本上所有文本模型都支持。
API密钥：创建并复制 [API密钥](https://token173.com/console/token) 填写
自定义请求地址：https://token173.com/v1/chat/completions
一定要填写这个不要填错。
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/651784/image-preview)
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/651786/image-preview)
确认添加后，使用时选择刚添加的模型。
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/651785/image-preview)
