# Codex 使用Token173 API教程

# 一、Codex 下载安装登录
按如下教程下载安装Codex。
[Codex Window系统安装教程](https://token173.apifox.cn/8863528m0.md)
[Codex Mac系统安装教程](https://token173.apifox.cn/8863529m0.md)
[Codex Linux系统安装教程](https://token173.apifox.cn/8863530m0.md)

运行 Codex。
登录时选择API KEY登录。
![224a1e7efd59f277c430663b94871f1b.png](https://api.apifox.com/api/v1/projects/8166793/resources/658672/image-preview)

输入在API [API密令管理](https://token173.com/console/token) 中创建的Codex专用的API KEY。
:::caution[]
Codex使用的API KEY只能选择 **Codex专属** 分组，选择其他分组将无法使用。
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/651452/image-preview)
:::

![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/658673/image-preview)

当前Codex登录进入后还不能使用，继续完成CC Switch配置

# 二、CC Switch 配置
按如下教程下载安装CC Switch。
[CC Switch Windows系统安装教程](https://token173.apifox.cn/doc-8676351)
[CC Switch Mac系统安装教程](https://token173.apifox.cn/doc-8676350)

运行 CC Switch。
选中 Codex，点击右上角的+号增加供应商。
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/651413/image-preview)

选择自定义配置
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/651415/image-preview)

下拉设置供应商信息
设置 供应商名称
官网链接设置为 https://token173.com
API KEY设置为在API [API密令管理](https://token173.com/console/token) 中创建的Codex专用的API KEY。
:::caution[]
Codex使用的API KEY只能选择 **Codex专属** 分组，选择其他分组将无法使用。
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/651452/image-preview)
:::
请求地址设置为 https://token173.com/v1
模型名称设置选择的模型名称，可以使用的模型可以在 [Codex可用模型](https://token173.com/pricing?group=Codex%E4%B8%93%E5%B1%9E) 链接中查看，正常只支持gpt的模型。推荐使用gpt-5.5。

![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/651444/image-preview)

设置完信息后点击右下角添加完成供应商设置。

最后回到Codex选项下选中刚设置的API供应商点击启用。

![image.png](https://api.apifox.com/api/v1/projects/8343734/resources/661794/image-preview)

# 三、Codex 使用
重启Codex。
使用简单命令测试是否正常。
第一次会提示初始化空间需要一些时间。
![10510cc7ac2f2b79b21b42b65e59d730.png](https://api.apifox.com/api/v1/projects/8166793/resources/658675/image-preview)
先将本地代码库文件夹创建为Codex项目，然后在项目下进行代码vibo coding。
![2395d6d77450490af4d676a73b2ae92f.png](https://api.apifox.com/api/v1/projects/8166793/resources/658676/image-preview)
