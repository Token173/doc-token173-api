# Cherry Studio 增加Gemini模型使用教程

# 一、增加服务商
进入 设置->模型服务->添加 来添加服务商
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/657327/image-preview)

供应商名称 可以随便填，为了好记可以加上OpenAI字样。
供应商类型 选上Gemini
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/657342/image-preview)


# 二、设置密钥地址
API密钥 按照 [API令牌创建教程](https://token173.apifox.cn/8863486m0.md) 教程创建好之后填上。
API地址 填 https://shiyunapi.com
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/657346/image-preview)


# 三、选择模型
模型 点击增加模型，填写模型名完成增加。
模型名建议直接从 [模型广场](https://shiyunapi.com/pricing?provider=Google) 复制。
推荐选上 **gemini-3.5-flash、
gemini-3.1-pro-preview**
 作为对话模型。
推荐选上 **gemini-3.1-flash-image-preview、gemini-3-pro-image-preview** 作为图片模型。这两个就是 Nano Banana。
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/657347/image-preview)

# 四、模型使用
### 1、对话使用
添加完成后可以选在对应模型进行对话
**gemini-3.5-flash、
gemini-3.1-pro-preview**
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/657349/image-preview)
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/657350/image-preview)

### 2、图片使用
添加完成后可以选在对应模型进行图片生成和编辑
**gemini-3.1-flash-image-preview、gemini-3-pro-image-preview**
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/657351/image-preview)
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/657353/image-preview)
