# gpt-image-2 Skill使用教程

# 安装教程

### 方法一、手动下载安装
从以下任意地址手动下载技能zip后在AI工具中手动上传安装。
1、skillhub地址：https://skillhub.cn/skills/gpt-image-2-shiyunapi
2、clawhub地址：https://clawhub.ai/gl894761214/gpt-image-2-shiyunapi
3、zip直接下载地址：https://img.skyai.tech/shiyunapi/gpt-image-2-shiyunapi.zip
3、github地址：https://github.com/gl894761214/gpt-image-2-shiyunapi

### 方法二、AI工具中搜索安装
如在AI工具中搜索安装技能，所有AI工具应该都类似。
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/652258/image-preview)

### 方法三、AI工具自动安装
复制以下命令给各种AI工具，AI工具会自动下载安装。

```js
帮我安装skill gpt-image-2-shiyunapi。
以下是skill gpt-image-2-shiyunapi 的多种下载途径，请帮我尝试安装。
1、zip直接下载地址：https://img.skyai.tech/shiyunapi/gpt-image-2-shiyunapi.zip
2、skillhub地址：https://skillhub.cn/skills/gpt-image-2-shiyunapi
3、clawhub地址：https://clawhub.ai/gl894761214/gpt-image-2-shiyunapi
4、github地址：https://github.com/gl894761214/gpt-image-2-shiyunapi
```

# 使用方法
对话时主动提到“**使用image2**”生成或编辑图片，或者提到“**使用诗云**”生成或编辑图片。
最保险的方式是在提示词中加“**使用诗云的image2**”生成或编辑图片。
只说生成图片或者编辑图片可能不会用到这个skill。
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/652264/image-preview)



第一次使用时AI会问你要API KEY, 你进入诗云[API令牌](https://shiyunapi.com/console/token)页面创建好API KEY之后发给AI就好了。
![image.png](https://api.apifox.com/api/v1/projects/8166793/resources/652266/image-preview)
