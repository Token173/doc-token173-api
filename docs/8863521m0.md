# OpenClaw配合CC switch自定义中转站配置教程

## OpenClaw配合CC switch自定义中转站配置

### 第一步：安装CC switch

1. **下载CC Switch并安装

下载地址：[下载CC Stitch](https://github.com/farion1231/cc-switch/releases)

2. **配置CC Switch**

添加供应商（中转站）

添加供应商（中转站）信息

选择添加

同时可以选择设置为默认渠道

### 第二步：安装openclaw与基础初始化

首先确保你已经安装了 Node.js 环境，然后在终端执行：

1. **全局安装：**
```bash
npm install -g openclaw@latest

```

2. **执行引导（根据提示完成基础设置）：**
```bash
openclaw onboard

```
**caht配置引导示例**
红框标注的地方为需要选择的地方

### 第三步：检查并启动

1. **启动 Gateway 服务：**
```bash
openclaw gateway --port 18789

```

2. **访问控制台：**
打开浏览器访问 `http://127.0.0.1:18789/`
