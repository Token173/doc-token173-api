### 第二步：安装openclaw与基础初始化

首先确保你已经安装了 Node.js 环境，然后在终端执行：

1. **全局安装：**
```bash
npm install -g openclaw@latest

```

2. **执行引导（根据提示完成基础设置）：**
```bash
openclaw onboard

```
**caht配置引导示例**
红框标注的地方为需要选择的地方
![image.png](https://api.apifox.com/api/v1/projects/5443236/resources/629056/image-preview)



### 第三步：检查并启动


1. **启动 Gateway 服务：**
```bash
openclaw gateway --port 18789

```

2. **访问控制台：**
打开浏览器访问 `http://127.0.0.1:18789/`
