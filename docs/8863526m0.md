# CC Switch Mac系统安装教程

# 安装包安装
方式一：无需魔法，点击 [下载链接](https://img.skyai.tech/shiyunapi/CC-Switch-macOS.dmg) 直接下载，运行按提示安装。

方式二：偶尔需要魔法，点击 [ccswitch github releases地址](https://github.com/farion1231/cc-switch/releases) 找到最新版mac下载，运行按提示安装。

# 命令行安装
也可以使用命令行安装。就两行命令，第二行命令同样因为格式原因，直接复制粘贴会报错。辛苦大家手敲一下，或者发给claude让他改了，再粘贴到终端。

```
brew tap farion1231/ccswitchbrew install --cask cc-switch
```

在终端粘贴，回车运行。

等他装好就成了。
