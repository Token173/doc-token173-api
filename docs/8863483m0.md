# 邀请奖励活动

邀请好友注册，好友充值获得10%现金奖励
## 一、活动入口
活动地址：[https://token173.com/console/topup](https://token173.com/console/topup)

## 二、参与流程
1. 诗云API用户免费参与
2. 进入活动页复制**专属邀请链接**
3. 分享链接给好友
4. 好友通过链接注册账号
5. 好友完成**前3次**充值即可触发奖励

## 三、奖励规则
1. 好友**前3次**充值，可获其充值金额10%现金奖励
2. 邀请人数不限，多邀多赚、上不封顶
3. 奖励长期有效

## 四、奖励使用
1. 直接提现：收益可随时申请提现
2. 划转余额：奖励可转入账户余额，抵扣模型调用费用

## 五、活动亮点
✅ 零成本参与，分享即赚钱
✅ 奖励可提现、可转余额，使用灵活
✅ 一键复制链接，分享便捷高效
